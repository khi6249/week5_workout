실시간으로 주차장의 빈자리를 찾아주는 스마트 주차 안내 시스템

기본 연결 확인: /api/health

프로젝트 정보 및 관리

누적 조회수: 0회

프로젝트 소개

본 프로젝트는 도심 및 대형 건물의 주차 공간 부족 문제를 해결하기 위해 기획되었습니다. 초음파 센서와 영상 인식을 활용해 빈 주차 공간의 실시간 정보를 수집하고, 사용자에게 웹 및 모바일 환경을 통해 가장 가까운 빈자리를 빠르게 안내합니다.

⭐ 주요 기능

  • 실시간 빈자리 탐색: 주차 구역별 주차 여부를 실시간으로 파악하여 지도 형태로 시각화 제공
  • 주차 자리 예약 시스템: 목적지 근처의 빈자리를 미리 선점하거나 안내받는 기능
  • 통계 및 리포트: 시간대별 주차 혼잡도 분석 데이터를 관리자에게 제공

🛠️ 사용 기술 (Tech Stack)

  • Backend: Python, Flask
  • Frontend: HTML5, CSS3, JavaScript
  • Server & Infra: Docker, Nginx (Reverse Proxy)
  • IoT / Database: Arduino/Raspberry Pi (센서 연동), SQLite/MySQL
